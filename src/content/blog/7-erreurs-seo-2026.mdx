## Erreur 1 : la cannibalisation de mots-clés

**Le problème :** plusieurs pages de votre site visent le même mot-clé. Google ne sait pas laquelle classer, donc il les classe toutes mal, ou en alterne sans cohérence.

**Comment détecter :**
- Recherche `site:votredomaine.com [mot-clé cible]` dans Google. Si plusieurs pages remontent, vous cannibalisez.
- Search Console → Performance → filtrer par requête. Si plusieurs URLs apparaissent pour la même requête, idem.

**Impact :** -3 à -10 positions sur la requête cannibalisée.

**Solutions :**
- Fusionner les pages redondantes (avec redirection 301)
- Différencier les angles : une page "qui je suis", une page "ce que je vends", une page "pour qui"
- Définir un mot-clé principal unique par page

J'ai détaillé un cas concret de cannibalisation dans la session de refonte de mon propre site : la home et la page service ciblaient toutes les deux "développeur web freelance Lyon". Le fix a consisté à repositionner la home sur "sites web et apps mobiles sur mesure".

### Erreur 2 : les balises title et meta description négligées

**Le problème :** title trop long, dupliqué, sans mot-clé. Meta description vide ou auto-générée.

**Comment détecter :**
- Search Console → Pages → vérifier les improvements suggérés
- Screaming Frog (gratuit jusqu'à 500 URLs) liste tous les title/meta du site

**Impact :** -10 à -30 pourcents de CTR à position égale, donc moins de clics et donc baisse progressive des positions (Google considère une page peu cliquée comme moins pertinente).

**Règles à respecter :**
- Title : 50-60 caractères, mot-clé en début, marque en fin
- Meta description : 150-160 caractères, valeur propositions claire, CTA implicite
- Unique pour chaque page du site

### Erreur 3 : le maillage interne défaillant

**Le problème :** vos pages clés (services, articles piliers) ne reçoivent pas de liens depuis les autres pages du site. Google les considère comme moins importantes.

**Comment détecter :**
- Outil Internal Linking dans Search Console : trier vos pages par nombre de liens entrants internes
- Une page importante avec moins de 3 liens internes est sous-maillée

**Impact :** vos pages les mieux travaillées sont reléguées en deuxième rideau alors qu'elles devraient porter le SEO.

**Règles :**
- Chaque article blog doit linker vers 2-3 articles connexes + 1 page commerciale
- Chaque page commerciale doit linker vers 1-2 pages services connexes + 1 article éducatif
- Le footer doit lister les pages clés (pas seulement les mentions légales)

### Erreur 4 : les Core Web Vitals au rouge

**Le problème :** votre site est lent ou instable visuellement. Google déclasse les pages avec des CWV "Médiocres" depuis 2021.

**Comment détecter :**
- Google Search Console → Signaux Web essentiels
- PageSpeed Insights pour le détail technique

**Impact :** -5 à -30 pourcents du trafic organique selon la magnitude.

**Solutions :**
- LCP : optimiser images, hébergement performant, CSS critique
- INP : réduire le JavaScript, différer les scripts tiers
- CLS : déclarer les dimensions des médias

Pour le guide complet, lisez [Core Web Vitals en 2026 : le guide complet](https://louisdecaumont.fr/blog/core-web-vitals-2026).

### Erreur 5 : l'absence de données structurées

**Le problème :** votre site ne fournit pas de Schema.org JSON-LD à Google. Vous perdez les rich snippets (étoiles, FAQ, prix, etc.) qui augmentent le CTR.

**Comment détecter :**
- Test des résultats enrichis : `https://search.google.com/test/rich-results`
- Search Console → Améliorations → vérifier les types de schema détectés

**Impact :** -10 à -25 pourcents de CTR par rapport à une concurrent qui affiche des étoiles ou un FAQ snippet.

**Schemas indispensables :**
- `Organization` ou `LocalBusiness` sur la home
- `Article` + `BreadcrumbList` sur chaque article blog
- `FAQPage` sur les pages avec FAQ
- `Product` sur les fiches e-commerce
- `Service` sur les pages services

### Erreur 6 : le contenu dupliqué (interne ou externe)

**Le problème :** plusieurs URLs servent le même contenu, ou votre contenu est copié depuis ailleurs (catalogue fournisseur, traduction automatique, contenu généré IA non retravaillé).

**Comment détecter :**
- Search Console → Pages → "Page en double, l'utilisateur n'a pas indiqué de version canonique"
- Copyscape pour vérifier l'unicité du contenu vs le web

**Impact :** Google choisit une seule URL à indexer (souvent la mauvaise), les autres sont ignorées. Pour le contenu copié, risque de pénalité Helpful Content.

**Solutions :**
- Canonical tags systématiques (`<link rel="canonical">`)
- Redirections 301 pour les variantes d'URL (avec/sans www, trailing slash, params UTM)
- Contenu original ou substantiellement enrichi par rapport aux sources

### Erreur 7 : pas de stratégie de mots-clés

**Le problème :** vous écrivez des articles "à l'instinct" sans recherche de mots-clés. Vous ciblez des requêtes ultra-compétitives ou inversement, sans aucun volume.

**Comment détecter :**
- Listez vos 10 derniers articles et leur mot-clé principal
- Vérifiez le volume de recherche dans Google Keyword Planner ou DataForSEO
- Vérifiez la concurrence (top 10 SERP) : si tous les résultats sont des sites avec un DR 70+, c'est inaccessible

**Impact :** vous publiez du contenu invisible. C'est l'erreur qui plombe le ROI éditorial des PME.

**Méthode :**
- Identifiez 3-5 clusters thématiques alignés sur votre activité
- Ciblez en priorité les mots-clés à volume moyen (100-1 000 recherches/mois) avec faible difficulté
- Utilisez Google Search Console pour identifier les requêtes où vous êtes en position 5-15 (quick wins)

## Le bonus : 3 erreurs moins fréquentes mais critiques

Ce ne sont pas dans le top 7, mais elles créent des dégâts sérieux quand elles arrivent.

### Robots.txt qui bloque par accident

Une `Disallow: /` oubliée dans le robots.txt bloque l'indexation de tout le site. C'est rare mais catastrophique. Vérification : tapez `votredomaine.com/robots.txt` et lisez. Aucune ligne `Disallow` ne devrait viser des pages publiques.

### Noindex sur des pages clés

Un `<meta name="robots" content="noindex">` sur la home tue le site dans Google. Souvent, c'est un staging qui passe en prod sans nettoyage. Vérifier avec View Source de chaque page importante.

### Migration sans plan de redirections

Refaire un site et changer les URLs sans redirections 301 = perte massive de positions. Pour le détail de la méthode, lisez [Migrer un site WordPress vers Next.js : la méthode complète](https://louisdecaumont.fr/blog/migrer-wordpress-vers-next-js).

## La méthode pour faire un audit SEO

Voici la séquence que j'utilise sur tous les audits.

1. **Vue d'ensemble** : trafic Search Console des 12 derniers mois, top pages, top requêtes
2. **Diagnostic technique** : robots.txt, sitemap, canonical, Core Web Vitals, mobile-friendly
3. **Diagnostic contenu** : structure des titres (H1-H3), longueur, mots-clés, doublons
4. **Diagnostic on-page** : title, meta, alt images, internal linking, schema
5. **Diagnostic off-page** : profil de backlinks (Ahrefs ou Search Console), branded queries, mentions
6. **Priorisation** : matrix impact/effort, top 5 chantiers à lancer dans le mois

Un audit complet sur un site de 50 à 200 URLs prend 1 à 2 jours de travail. Le rapport délivre 20 à 40 actions concrètes priorisées.
